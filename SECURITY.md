# Security Policy

The security of Free Media Engine (FME) and its self-hosted operators is of paramount importance.

---

## 🛡️ Supported Versions

Only the latest release on the `main` branch receives active security updates and vulnerability patches.

| Version | Supported |
| :--- | :--- |
| `v1.0.x` | ✅ Yes |
| `< v1.0.0` | ❌ No |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or exploit in Free Media Engine, **please do not open a public issue on GitHub**.

Instead, please report it via one of the following methods:
1. **GitHub Private Vulnerability Reporting**: Submit a private advisory directly through the repository's **Security** tab.
2. **Email Disclosure**: Email the maintainers at `security@yourdomain.com` with the subject line `[SECURITY] Free Media Engine Vulnerability`.

### Please Include:
- A detailed description of the vulnerability.
- Proof-of-concept (PoC) code or exact steps to reproduce.
- Potential impact and affected components (Daemon, WebSocket Bridge, Extension, or Auth).

We appreciate responsible disclosure and will acknowledge receipt within 48 hours and work on a patch promptly.
